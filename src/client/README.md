# Client (Vue + Vite + Tailwind)

Frontend part of **fireart-test-task** — a single Vue 3 island (`PlayersApp.vue`) mounted into the server‑rendered EJS team page.

## Scripts

```bash
npm install          # install client deps
npm run dev          # Vite dev server with HMR — http://localhost:5173
npm run build        # production build → ../../public/assets
npm run preview      # preview the built bundle
```
